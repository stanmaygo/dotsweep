# dotsweep-skill

The published agent skill for [dotsweep](https://dotsweep.com), and its
packaging. Nothing else lives here.

## This repo is a mirror, not the source

`skills/dotsweep/SKILL.md` is **generated by copying**, from the engine
repository that also holds the Go CLI and the Cloudflare Worker. Editing it
here is how the two come to disagree: the next sync overwrites the change, and
the hosted `dotsweep.com/skill.md` — which is what the paste-one-message
install actually fetches — keeps serving the other version. Two installs of the
same skill then behave differently with nothing reporting it.

**Edit the prompt in the engine repo, then run `scripts/sync-skill.sh` here.**

## What must stay true

- **The root `SKILL.md` is a symlink**, so the prompt exists exactly once. A
  second copy is the same drift in miniature, and `npx skills add` reads the
  root path while a manual installer reads `skills/dotsweep/`.
- **The version lives in two files** — `metadata.version` in the skill
  frontmatter and `version` in `.claude-plugin/plugin.json` — and they must
  move together. `marketplace.json` deliberately carries none, so `plugin.json`
  stays the single source of truth.
- **No machine-specific paths and no API host but `dotsweep.com`** in the
  prompt. Both were violated once in the commit that added the check for them.

`scripts/validate-package.py` asserts all of the above and runs in CI. It exists
because packaging fails in a way no test notices: the skill installs and
silently does nothing, because what broke was frontmatter, a version, or the
symlink.

## What is deliberately absent

The engine — the Go CLI, the Worker, the policy data, the WHOIS phrase tables —
is not here and is not what this repo is for. The skill calls the hosted API, so
it needs none of it.
